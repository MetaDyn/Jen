# Canvas Demo

A minimal static demo page for testing Canvas rendering and easy external hosting.

## Files
- `index.html`
- `styles.css`
- `app.js`

## Local use
You can serve this folder with any static server, for example:

```bash
cd canvas-demo
python3 -m http.server 8080
```

Then open:
- `http://localhost:8080`

## Static hosting
This folder is build-free and can be uploaded directly to:
- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel static hosting
- any nginx/Apache/static bucket setup

## Notes
No build step required.
No external dependencies required.
