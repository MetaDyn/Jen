# MetaDyn Daily Agendas

This folder tracks Josh's daily MetaDyn agendas over time.

## Structure

- `March-2026/` — daily agendas for March 2026
- `April-2026/` — daily agendas for April 2026

## Naming convention

Use one file per day:

- `YYYY-MM-DD-metadyn-daily-agenda.md`

## Purpose

These docs provide a lightweight operating trail for:

- daily priorities
- platform / product focus
- community / Discord rhythm
- beta / user outreach
- business / strategy / coordination
- optional stretch work

This is meant to help track momentum and decision-making across the MetaDyn build.
