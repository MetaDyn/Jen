# MetaDyn Opportunity Briefs

This folder tracks recurring research briefs about outreach opportunities for MetaDyn immersive spaces and related platform capabilities.

## Structure
- `April-2026/` — April 2026 briefs

## Naming convention
Use one file per run:
- `YYYY-MM-DD-metadyn-opportunity-brief.md`

## Purpose
These docs provide a lightweight business-development research trail for:
- Kansas City opportunities
- national opportunities
- global opportunities
- positioning guidance for cold outreach
- segmentation across small, medium, and enterprise targets
