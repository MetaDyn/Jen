# Opportunity Folders

This directory holds one folder per strategic MetaDyn opportunity.

Each opportunity folder should contain a compact action package so the team can move from research to outreach quickly.

## Standard contents
- `README.md` — quick index and status
- `opportunity-assessment.md` — research and strategic evaluation
- `outreach-concept-note.md` — concise concept note tailored to the opportunity
- `cold-outreach-email.md` — ready-to-edit outreach draft
- `positioning-template.md` — reusable positioning and talking points for the opportunity

Add more files only when the opportunity genuinely needs them.
