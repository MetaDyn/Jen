# Canary Islands Tourism Digital Twin Opportunity

## Status
- **Stage:** researched / packaging for outreach

- **Priority:** high-interest strategic opportunity

## What this folder contains
- `opportunity-assessment.md` — full research and strategic fit assessment
- `outreach-concept-note.md` — concise concept note framing MetaDyn as the immersive experience layer
- `cold-outreach-email.md` — draft outreach email for EMOTUR / ULPGC / destination stakeholders

## Core thesis
MetaDyn should not pitch itself here as the raw tourism digital twin backend. It should position itself as the **immersive access, interaction, and continuity layer around the digital twin**.
