What this map currently encodes

  • Cloudflare as the universal external control plane.
  • Netlify as the frontend/static hosting layer under MetaDyn-managed domains.
  • AWS EC2 as the current stage and several project-origin surfaces.
  • Hetzner as the primary prod/native-services box.
  • The on-prem Azure Stack rack as a hybrid dev environment behind 136.34.121.206.

What still needs refinement

  • Exact internal service placement behind Hetzner nginx.
  • Precise machine-by-machine mapping inside the on-prem rack.
  • Databases, storage, CI/CD, and any private east-west flows.
  • Which Cloudflare surfaces are intentional DNS-only exceptions versus legacy behavior.
